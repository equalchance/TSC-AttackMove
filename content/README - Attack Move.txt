Tiberian Sun Client Attack Move — experimental build

Unzip the entire folder to a short local path and run TiberianSun.exe.
Start a fresh scenario and make new saves with this build.

Select units, press A, then click a ground destination. Eligible combat units
engage targets along the route and continue moving afterward. Medics and
compatible repair vehicles can help wounded allies along the route. Unarmed
units in the selection receive an ordinary Move order. A successful order exits
targeting but keeps the units selected. Invalid destinations remain active for
retry. Right-click cancels targeting; Move or Stop replaces the stored route.

The default acquisition radius is 1.5 times the selected weapon range; target
retention is 3 times that range. Native in-range eligibility is preserved.
These settings do not change firing range. Mod authors can configure ranges,
repeated destination clicks, right-click deselection, defense/wildlife targeting,
and support behavior through the Attack-Move developer kit's INI presets.

This configurable revision uses new protocol and save identifiers. Start a
fresh game; saves from previous attack-move builds are incompatible.
Native gameplay status is recorded in the separate acceptance receipt.
Multiplayer remains unverified until matching builds are tested together.
